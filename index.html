How I work

A simple, repeatable process that ships fast without cutting corners. I use AI (Claude) to speed up the build, and I review, test and own every line.

01

Research

I study the best-performing sites in the client's niche before writing any code, so the design is based on what already converts.

02

Build

Mobile-first, hand-coded and lightweight. No page builders, no bloat, clean code any developer can pick up.

03

Test

Real phone and desktop checks, form validation, edge cases and image compression before anything goes live.

04

Ship

Deployed on Netlify, versioned on GitHub, with a clear README so the hand-off is easy.
